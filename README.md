# 🛍️ CampusKart — متجر الجامعة

## ✨ المميزات

### 🛒 واجهة المتجر
- ✅ صفحة رئيسية مع Hero، أقسام، منتجات مميزة، وشريط ميزات
- ✅ صفحة كاملة للمنتجات مع فلتر بالأقسام + بحث
- ✅ صفحة مستقلة لكل قسم
- ✅ صفحة سلة مع تحكم كامل بالكميات + ملخّص طلب لحظي
- ✅ صفحة "عن المتجر"
- ✅ وضع ليلي / نهاري
- ✅ تصميم متجاوب بالكامل (Desktop / Tablet / Mobile)

### 💰 نظام الأسعار الديناميكي
- ✅ السعر الأساسي يُدخَل **بالدولار فقط**
- ✅ السعر بالليرة التركية والسورية يُحسَب **تلقائيًا** بحسب أسعار الصرف
- ✅ تعديل أسعار الصرف يُحدِّث جميع المنتجات مباشرة

### 📱 إرسال الطلب عبر واتساب
- ✅ الضغط على زر الطلب **يفتح واتساب مع الرسالة جاهزة** (لا يُرسل تلقائيًا)
- ✅ أسماء المنتجات بخط عريض (`*name*` في تنسيق واتساب)
- ✅ الإجمالي بالعملات الثلاث: التركي، السوري، الدولار
- ✅ ملاحظة اختيارية تُضاف للرسالة عند وجودها

### ⚙️ لوحة تحكم احترافية
- ✅ تسجيل دخول بكلمة مرور (افتراضية: `admin`)
- ✅ إحصائيات على الرئيسية
- ✅ **إدارة الأقسام**: إضافة، تعديل، حذف
- ✅ **إدارة المنتجات**: إضافة، تعديل، حذف، بحث، فلترة
- ✅ **أسعار الصرف**: تحكم كامل + معاينة
- ✅ **رسالة الواتساب**: تحكم بالنصوص + معاينة حيّة
- ✅ **الإعدادات**: اسم المتجر، الشعار، كلمة المرور، المميزات
- ✅ **البيانات**: تنزيل / نسخ / استيراد `store.json`

## 🚀 التشغيل والنشر

### الطريقة 1: تشغيل محلي للتجربة

```bash
# افتح مجلد المشروع
cd campuskart

# شغّل خادم محلي (لأن الموقع يستخدم fetch لتحميل JSON)
python3 -m http.server 8000

# ثم افتح المتصفح على:
# http://localhost:8000
```

### الطريقة 2: النشر على Netlify + GitHub

1. **أنشئ مستودعًا على GitHub** وارفع جميع الملفات إليه.
2. **اربطه بـ Netlify**:
   - افتح [netlify.com](https://netlify.com) → "Add new site" → "Import an existing project"
   - اختر مستودع GitHub الخاص بك
   - اضغط **Deploy** (لا تحتاج إلى أي أوامر بناء)
3. سيصبح موقعك متاحًا خلال ثوانٍ على رابط `https://your-site.netlify.app`

---

## 🔄 كيفية تحديث المتجر بعد النشر

1. افتح `https://your-site.netlify.app/admin/` — أدخل كلمة المرور.
2. عدّل ما تريد (منتجات / أقسام / أسعار / رسالة).
3. اذهب إلى **الإعدادات** → **تنزيل store.json**.
4. ارفع الملف الجديد إلى GitHub (استبدل الملف القديم في مجلد `data/`).
5. Netlify سيقوم بإعادة النشر تلقائيًا خلال ثوانٍ.

**💡 بديل سريع:** بدلاً من التنزيل والرفع، استخدم زر **"نسخ محتوى JSON"** ثم الصقه في GitHub عبر تعديل الملف من واجهة الويب.

|---|---|---|
